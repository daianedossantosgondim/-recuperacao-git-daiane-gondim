# Respostas Teóricas - Git e GitHub

1. **O que é um repositório?**
   É um local de armazenamento digital onde ficam guardados todos os ficheiros do projeto, juntamente com todo o histórico de alterações e commits realizados.

2. **Qual a diferença entre Git e GitHub?**
   O Git é o sistema de controlo de versões executado localmente na máquina. O GitHub é uma plataforma na nuvem que hospeda repositórios Git na web.

3. **Para que serve um commit?**
   Serve para registar um ponto na história do projeto (um snapshot), guardando o estado atual dos ficheiros modificados com uma mensagem explicativa.

4. **Por que utilizamos branches?**
   Utilizamos branches para isolar o desenvolvimento de novas funcionalidades sem alterar o código principal (main).

5. **Qual a finalidade de um Pull Request?**
   Solicitar a integração das alterações feitas numa branch secundária para a branch principal (main), permitindo a revisão de código.

6. **Qual a diferença entre fazer um commit e fazer um push?**
   O commit guarda as alterações localmente no computador. O push envia esses commits para o repositório remoto no GitHub.

7. **O que acontece quando um Pull Request é realizado?**
   É criada uma solicitação no GitHub onde os desenvolvedores podem comparar o código, adicionar comentários e aprovar a união das branches.

8. **Qual a finalidade do merge?**
   Incorporar (fundir) as alterações e o histórico de commits de uma branch específica dentro de outra branch.

9. **Por que não é recomendado realizar todo o desenvolvimento diretamente na main?**
   Porque pode introduzir erros no código estável em produção, dificultar a revisão por outros membros e causar conflitos frequentes no histórico.
